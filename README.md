<h1 align="center"> The Unlucky Farmer: The Video Game </h1>
  
<br>



<h2 align="left"> Game Architecture: </h2>
     
      - Godot Game Engine
      - x64/x86 CPU
      - 4GB RAM 
      
<br>



<h2 align="left"> Summary: </h2>

  <p> An RPG game about an unlucky farmer out to discover the truth behind their family's curse after their father's untimely passing. Save the farm from financial ruin, 
  find the truth, and stop the curse. Upgrade your tools, plant crops, make money. It's up to you now! </p>
  
<br>



<h2 align="left"> Workflow Rules: </h2>
    
     - 1) Each new feature gets a branch derived from the Dev branch 
     - 2) Nothing gets merged without entering the PR process
     - 3) 1 person MINIMUM must approve your changes before merging 
     - 4) Once approved, new features are implemented into the stable branch 
     - 5) Main should only have 1 commit from Dev. (Game Documentation additions are exempt from this rule) 

<br>



<h2 align="left"> Project Branches: </h2>

    - DEV: Reserved for builds with implemented feature-sets
    - MAIN: The "market" ready product (excluding doc additions)
    - HOTFIX: Bug fixes for pre-existing features 
    - BKUP: Weekly backup of the DEV branch
